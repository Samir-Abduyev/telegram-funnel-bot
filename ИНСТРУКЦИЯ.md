# Бот-воронка: инструкция

Что делает бот: человек приходит из канала и нажимает /start. Бот присылает бесплатные видеоуроки по одному. Во 2-м уроке человек присылает видео-задание, оно приходит вам. После последнего урока бот предлагает оплату. Человек присылает чек, вы нажимаете «Подтвердить», и бот впускает его в закрытую группу. Тем, кто застрял, бот напоминает через 1 и 3 дня (только с 10:00 до 21:00 по Баку).

Все тексты для учеников на азербайджанском. Вам бот пишет по-русски.

---

## 1. Подготовка (один раз)

### 1.1 Бот
1. В @BotFather создайте бота командой `/newbot` и скопируйте токен.
2. Узнайте свой числовой id у @userinfobot. Это число вида `123456789`.

### 1.2 База данных (Supabase, бесплатно)
1. Зайдите на supabase.com и создайте **новый проект** (New project). Регион выберите **Frankfurt (eu-central-1)**: он ближе всего к Баку. Пароль базы сохраните у себя.
   - Можно взять и существующий проект VibeCeh: таблицы бота лежат в отдельной схеме `funnel` и ничего не трогают. Но отдельный проект надёжнее, и в Frankfurt бот отвечает быстрее.
2. Откройте **Connect → Session pooler** и скопируйте строку подключения `postgresql://…`. Вместо `[YOUR-PASSWORD]` подставьте свой пароль.

### 1.3 Файл `.env`
В папке `funnel-bot/bot` скопируйте `.env.example` в `.env` и **сами** впишите:

| Строка | Что вписать |
|---|---|
| `BOT_TOKEN` | токен из BotFather |
| `OWNER_ID` | ваш id из @userinfobot |
| `OWNER_CONTACT` | ваш контакт, например `@username`; его увидят те, кто выберет «Kartla ödəniş» |
| `PAYMENT_URL` | ссылка на оплату (https://…). Если оставить пустой, кнопки «Ödəniş linki» не будет |
| `DATABASE_URL` | строка из Supabase |
| `GROUP_ID` | пока пусто, заполните в шаге 3 |

Токен и пароль базы никому не пересылайте, и мне в чат тоже.

### 1.4 Таблицы и запуск
В терминале выполните:
```bash
cd "C:/Users/Samir/Downloads/Развитие сообщество/funnel-bot/bot"
npm install
npm run migrate
npm start
```
Должна появиться строка `@имя_бота is running`. Остановить бота: Ctrl+C.

## 2. Уроки (в личке с ботом, с телефона)
1. Напишите боту `/help`: там список всех команд.
2. `/set 1`, затем пришлите **видео урока 1 с подписью**. Подпись = текст урока, до 1024 символов. Бот ответит «✅ Сохранено».
3. Так же `/set 2`, `/set 3`, `/set 4`.
4. `/task 2`: урок 2 станет уроком с заданием. Кнопки «Dərsi bitirdim» там не будет, и урок 3 откроется только после того, как человек пришлёт видео.
5. **Оплата стоит под последним уроком.** Бот сам ставит под ним кнопки «💳 Onlayn ödəniş», «🏦 Kartla ödəniş» и «✅ Ödədim». Призыв к оплате (цену и что входит) напишите в подписи к последнему уроку.
6. Ученик заходит и видит только приветствие и кнопку «▶️ Pulsuz dərslərə başla». Начиная с урока 2, под уроком появляется «📚 Dərslər» — база знаний, где только **пройденные** уроки. «💬 Adminlə əlaqə» (ваш TG) есть только под последним уроком. Название урока в «Dərslər» — это первая строка подписи, например «Hazırlıq günü».
7. Чат ученика не засоряется: при нажатии «Növbəti dərs ➡️» прошлый урок исчезает и появляется новый.
8. Необязательно: `/set welcome` задаёт своё приветствие. Посмотреть стандартное: `/show welcome`.
9. Поменять уроки местами: `/swap 2 3`.
6. Проверка: `/lessons` показывает, что заполнено, `/show 2` показывает урок так, как его видит ученик.

Чтобы заменить урок, снова выполните `/set N` и пришлите новое видео. Люди, которые уже на этом шаге, получат новое видео при следующем показе.

## 3. Закрытая группа
1. Добавьте бота в группу и сделайте его **админом** с правом **«Пригласительные ссылки» (Invite users via link)**.
2. Бот сам напишет вам: «ID этого чата: -100…». Впишите в `.env` строку `GROUP_ID=-100…` и перезапустите бота.

Как человек попадает в группу: после вашего «Подтвердить» он получает кнопку «👥 Qrupa qoşul» и отправляет заявку, а бот её сразу одобряет. Если ссылку перешлют постороннему, его заявка останется висеть: бот одобряет только тех, чей чек вы подтвердили. Чужие заявки можно одобрить или отклонить вручную в настройках группы.

## 4. Работа каждый день
- **Чек** приходит вам фото или файлом с кнопками «✅ Подтвердить / ❌ Отклонить». Если отклоните, ученик получит вежливый отказ и сможет прислать чек заново.
- **Видео-задания** приходят вам пересылкой. Ученик при этом уже идёт дальше, ваш ответ не нужен.
- **Ответ ученику через бота.** На видео-задании или чеке нажмите «Ответить» и напишите ответ: текстом, голосом или видео. Бот отправит его ученику с пометкой «Mentordan cavab».
- **Напоминание о чеках.** Если чек ждёт вашего решения больше 2 часов, бот один раз напомнит, ответом на сообщение с чеком (только с 10:00 до 21:00).
- **Рассылка.** `/broadcast offer` → пришлите сообщение → бот покажет, как оно будет выглядеть → «✅ Отправить». Сегменты: `offer` (дошли до оплаты, но не оплатили), `lessons` (ещё на уроках), `paid` (оплатили), `all` (все). Не злоупотребляйте: частые рассылки = блокировки бота.
- Уроки и рассылки защищены: их нельзя скачать или переслать. Запись экрана Telegram полностью не блокирует.
- `/stats` показывает, сколько людей на каждом уроке, сколько дошло до оплаты и сколько оплатило.
- Ссылка для канала: `https://t.me/имя_бота?start=kanal`. Слово после `start=` бот запоминает как источник, так можно делать разные ссылки для разных мест.
- `/reset` стирает только **ваш** прогресс: после этого можно пройти воронку как ученик через `/start`.

## 4а. Если бот не работает — он сам вам пишет
Сообщения приходят вам в личку от бота:
- **🚨 Ошибка при обработке действия** — что сломалось (📍 где: какая кнопка/команда и у какого ученика), текст ошибки и 💡 что делать. Одна и та же ошибка — не чаще раза в 30 минут (потом «повторилось ещё N раз»).
- **🚨 Нет связи с базой данных** — проверка раз в минуту; когда связь вернётся — «✅ Связь с базой данных восстановлена».
- **🚨 Напоминания ученикам не отправились**, **🚨 Бот ОСТАНОВИЛСЯ** (например, запущена вторая копия) — с причиной.
- При каждом запуске: «✅ Бот запущен» или **«⚠️ Бот снова работает, но был недоступен с … до … (≈N мин)»** — если он пропадал без предупреждения (сон или выключение компьютера, нехватка памяти, сбой).

На сервере после сбоя бота сам перезапускает systemd (встроенный «смотритель» Ubuntu), а при запуске бот присылает вам «✅ Бот перезапущен» / «был недоступен с … до …».

## 5. Сервер (VPS) — бот работает здесь 24/7 (с 18.11)
**Где:** Vultr (хостинг), Амстердам, тариф vc2-1c-1gb — $5/мес. Ubuntu 24.04. **IP-адрес и готовые команды — в файле `PRIVATE.md` рядом** (он есть только на вашем ПК и в GitHub не попадает).
Вход только по SSH-ключу (пароль root отключён). Ключ лежит у вас: `C:\Users\Samir\.ssh\id_ed25519` — никому не отправляйте.
Если ПК со ключом пропадёт: Vultr → сервер → «View Console» (окно сервера в браузере) → войти паролем root из панели Vultr.

⚠️ **На компьютере бота больше НЕ запускайте** (ни `npm start`, ни `npm run forever`): две копии одного бота не могут работать одновременно (ошибка 409).

Команды — в терминале на ПК (кнопка Run рядом с блоком):
- Состояние: `ssh root@<IP сервера> systemctl status funnel-bot`
- Логи (последние 50 строк): `ssh root@<IP сервера> journalctl -u funnel-bot -n 50 --no-pager`
- Перезапуск: `ssh root@<IP сервера> systemctl restart funnel-bot`
- Обновить код на сервере (после изменений на ПК; `.env` и данные в базе не трогаются):
```bash
cd "C:/Users/Samir/Downloads/Развитие сообщество" && tar czf - --exclude=node_modules --exclude=bot/.env --exclude=PRIVATE.md --exclude=.git funnel-bot | ssh root@<IP сервера> 'rm -rf /root/upload && mkdir -p /root/upload && tar xzf - -C /root/upload && bash /root/upload/funnel-bot/deploy/update.sh'
```
- Поменять что-то в `.env` на сервере: `ssh root@<IP сервера>` → `nano /opt/funnel-bot/bot/.env` → сохранить (Ctrl+O, Enter, Ctrl+X) → `systemctl restart funnel-bot`.

Если бот не стартует и в логе «Ошибки в .env», исправьте указанную строку и перезапустите бота.
